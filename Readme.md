# Comic Style Portfolio

A keyboard controlled comic style portfolio, built like a comic where you access modals like comics. Specially designed for Tabbed (goated) ysws.

Live Link: [Here](https://raze-me.github.io/my-site/)

## Controls

| Key | Action |
| --- | --- |
| `←` / `→` | Move between tiles |
| `Enter` | Select the active tile |
| `Esc` | Go back / close the current dialog box |
| `R` | Give a random recomendation from me (in V2) |
| --- | --- |

The cursor is hidden by default. A mouse click temoporarily reveals it for two seconds before hiding it again.
